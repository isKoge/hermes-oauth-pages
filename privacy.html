隐私政策

Hermes Drive Access · 最后更新 2026-10-27

1. 适用范围

本政策适用于 Hermes Drive Access（下称“本应用”）。本应用是仅供其所有者个人使用的本地自动化工具，不向公众提供服务，不收集第三方用户的任何信息。

2. 我们访问哪些数据

在所有者本人完成 Google OAuth 授权后，本应用可以通过 Google Drive API 访问该账号中的文件、文件夹及其元数据（名称、类型、大小、修改时间）。访问范围限于完成所有者下达的具体任务（例如搜索、下载、上传、整理文件）。

3. 数据存放在哪里

  • 授权令牌：保存在所有者本人的电脑上，文件权限为仅本人可读（0600）。
  • 文件内容：仅在执行任务时于本机与 Google 服务器之间直接传输，不写入任何第三方数据库，不上传到应用作者的服务器——本应用没有服务器。
  • 日志：仅在本机记录操作记录（例如“已下载某文件”），用于排查问题，不包含文件内容。

4. 数据共享

不共享、不出售、不转让任何数据给第三方。除 Google 官方 API 之外，本应用不向任何外部服务发送数据。

5. 数据保留与删除

所有者可随时撤回授权（访问 Google 账号权限页），撤回后本应用立即失去访问能力；本地令牌文件可随时删除。文件本身始终保存在所有者的 Google 云端硬盘中，本应用不会另行留存副本。

6. 安全

令牌仅存放于本机并限制文件权限；不在日志、配置或代码中明文记录令牌内容。所有 API 请求通过 HTTPS 直连 Google 官方端点。

7. 儿童隐私

本应用不面向儿童，也不收集任何人的个人信息。

8. 政策变更

若本政策发生变更，将更新本页面顶部的日期。
